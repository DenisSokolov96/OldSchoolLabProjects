# 🏺 OldSchoolLabProjects

Коллекция программ на **Turbo Pascal 7.0** и **x86 Assembly (TASM)**. Проекты эпохи 16-битного реального режима DOS, включающие объектно-ориентированную графику, системные утилиты и математические модели.

---

## 🚀 Основные проекты в репозитории

### 🌌 Solar System Model (OOP Edition) (каталог `/TP7`)
Интерактивная модель Солнечной системы, построенная на иерархии объектов.
*   **Особенности**: Использование наследования (`inherited`), виртуальные методы, работа с графикой VGAHi (640x480).
*   **Управление**: Изменение скорости системы в реальном времени, выбор планет мышью, динамический вывод названий объектов.
*   **Технологии**: `Graph`, `Crt`, `Mousem`, `Figurem`.

### 🎹 ASM Digital Organ (каталог `/TASM`)
Низкоуровневый музыкальный инструмент, управляющий системным динамиком (PC Speaker).
*   **Особенности**: Прямая работа с портами ввода-вывода (`61h`, `42h`) и программирование системного таймера 8253/8254.
*   **Функционал**: Генерация звука разной частоты на основе ASCII-кодов нажимаемых клавиш.
*   **Технологии**: TASM, прерывания BIOS `int 15h` (задержки) и `int 21h` (I/O).

### 🌈 Interrupt-Driven Rainbow Banner (каталог `/TASM`)
Динамический текстовый баннер, работающий через перехват системного прерывания таймера.
*   **Особенность**: Программа перехватывает вектор `int 1Ch` (пользовательский тик таймера, ~18.2 раза в секунду).
*   **Низкоуровневый доступ**: Отрисовка происходит путем прямой записи символов и атрибутов цвета в сегмент видеобуфера B800h (текстовый режим 03h).
*   **Эффекты**: Динамическая смена палитры символов ("бегущая радуга") и использование расширенных ASCII-символов псевдографики для отрисовки рамки.
*   **Технологии**: Манипуляция векторами прерываний (`int 21h` функции `35h` и `25h`), сегментная адресация видеопамяти, сохранение контекста процессора в обработчике.

## 🛠 Технологический стек

*   **Язык**: Turbo Pascal 7.0 (Borland, 1992)
*   **Ассемблер**: TASM (Turbo Assembler)
*   **Архитектура**: x86 Real Mode (16-bit)
*   **Графика**: VGA Driver (`EGAVGA.BGI`)

### 🛠 Ассемблер
*   **Компилятор**: TASM (Turbo Assembler) / MASM.
*   **Линковщик**: TLINK.
*   **Платформа**: MS-DOS (Real Mode).

## 💻 Как запустить на современных системах

Так как проекты являются 16-битными, они не запускаются напрямую в современных Windows 11 или Linux (Manjaro).

### Для пользователей Linux:
Рекомендуется использовать **DOSBox-X**:
1. Установите эмулятор: `sudo ... dosbox-x`
2. Смонтируйте папку проекта: `mount c ~/OldSchoolLabProjects`
3. Каталог TASM - программы на Turbo Assembler, TP7 - программы на Turbo Pascal 7
4. Запустите исполняемые файлы

Если вы хотите собрать проект как нативный 64-битный файл Linux:
